# Сценарии ручной проверки на демо-базе

Все примеры обезличены. Проверка идёт на демо-базе (`data/demo.db`, `APP_MODE=demo`) с **тестовым** ботом: [QUICK_START.md](QUICK_START.md). В демо-выпуске все карточки опубликованы и «подтверждены» тестовым автором, названия начинаются с «[ТЕСТ]», в сообщениях есть плашка «ДЕМО-база». Реальной проверки правил это не заменяет.

Ожидаемые статусы выведены из логики карточек (`src/bginfo/seed/grounds/*.yaml`) и движка. Формулировки статусов в боте:

| Значок | Статус |
|---|---|
| ✅ | Предварительно подходит |
| ❔ | Нужно уточнить |
| 🟡 | Возможно после выполнения условия |
| 🧑‍⚖️ | Нужен индивидуальный разбор |
| ⛔ | Не подходит по указанным данным |

Общее: каждый сценарий начинается с `/restart` (чистая анкета), после последнего вопроса бот показывает проверку анкеты, нажмите «✅ Всё верно — показать результат». Порядок вопросов задаёт приоритет в базе; ответы ниже перечислены по смыслу, а не по порядку.

## 1. Только кнопки: пенсионер

Нажмите «Подобрать вариант». Ответы:

- Для кого: «Для себя»; гражданство: «Другой страны»; где живёте: «В стране своего гражданства»;
- Занятость и доходы: «Получаю пенсию»; связи с Болгарией: «Ничего из этого»;
- Пенсия в месяц: `700`; документ о пенсии: «Да»; жильё в Болгарии: «Да»; цель: «Просто жить в Болгарии».

Ожидание: главный вариант «[ТЕСТ] ВНЖ для пенсионеров» со статусом ✅ «Предварительно подходит»; остальные основания не выше ⛔ (в разделе «Не подходит» или не показаны). Внизу «Версия базы правил: №1», дисклеймер «предварительный подбор».

Варианты проверки:

- пенсия `300` (ниже минимальной 347,51 €): 🧑‍⚖️ «Нужен индивидуальный разбор»;
- пенсия `700`, жильё «Нет»: 🟡 «Возможно после выполнения условия» (нужно оформить жильё);
- пенсия «Не знаю»: ❔ «Нужно уточнить».

## 2. Свободный текст

Нужен `OPENROUTER_API_KEY`. Нажмите «Описать ситуацию самому» (или просто напишите) и отправьте:

> Я пенсионер из Казахстана, пенсия около 700 евро, жена тоже на пенсии, хотим переехать вместе, квартиру в Варне уже купили

Ожидание:

- уведомление об AI-анализе текста показано в приветствии и при выборе «Описать ситуацию самому» (а если человек пишет текст, не видев его, то перед разбором);
- бот пересказывает **распознанное для подтверждения**: гражданство другой страны, пенсия, переезд с супругой, жильё есть, пенсия ≈ 700 €. Ничего не принимается без подтверждения («Да, верно» / «Нет, исправить»);
- далее бот задаёт только недостающие вопросы (например, документ о пенсии, данные супруги);
- итог: «[ТЕСТ] ВНЖ для пенсионеров» ✅ после ответа «Да» про документ о пенсии, плюс блок о супруге.

Без ключа OpenRouter: «Сейчас не получается разобрать текст (сервис разбора недоступен). Ничего не потеряно — продолжим кнопками.» и анкета продолжается кнопками.

Дополнительно: на вопрос о сумме ответьте текстом `850 евро` или `1400 лева` (≈ 716 €): число принимается без AI; ответ в рублях — просьба указать сумму в евро.

## 3. Пенсионер с женой

Кнопками: «Для себя и семьи» → «Супруг(а)»; основной заявитель — как в сценарии 1 (пенсия `700`, документ «Да», жильё «Да»). Для супруги: гражданство «Другой страны», доходы «Ничего из этого», документ о браке «Да».

Ожидание:

- главный вариант для заявителя: ✅ «ВНЖ для пенсионеров»;
- блок «Семья»: «Супруг(а)», основание «ВНЖ для члена семьи иностранца с видом на жительство» — 🟡 «Возможно после выполнения условия». Причина: у основного заявителя пока нет разрешения на пребывание не меньше года (для людей, которые ещё не живут в Болгарии, статус считается «нет статуса»). Значок ✅ для супруги быть не должен.

## 4. IT-удалёнщик

Кнопками: для себя; гражданство «Другой страны»; доходы «Работаю удалённо по найму в иностранной компании»; связи «Ничего из этого»; работодатель за пределами ЕС: «Да»; доход за прошлый год `40000`; «Может ли компания открыть представительство?» «Нет»; жильё «Да»; цель «Работать в Болгарии».

Ожидание: главный вариант «ВНЖ для цифровых кочевников (Digital nomad)» ✅; «торговое представительство» — ⛔ (компания представительство открыть не готова).

Граничные проверки:

- доход `31010` (ровно 50 МРЗ при МРЗ 620,20 €): ✅; `31009`: 🧑‍⚖️ «Нужен индивидуальный разбор»;
- жильё «Нет»: 🟡 «Возможно после выполнения условия»;
- работодатель в ЕС («Нет» на вопрос о месте регистрации): основание не подходит ⛔, результат «ни одно основание не подходит».

## 5. Фрилансер с клиентами в Болгарии: не подходит

Кнопками: для себя; гражданство «Другой страны»; доходы «Фриланс или ИП с зарубежными клиентами»; связи «Ничего из этого»; работает на клиентов не меньше года «Да»; **будет работать на клиентов в Болгарии: «Да»**; доход за прошлый год `35000`; жильё «Да».

Ожидание: ни одного ✅/🟡: сообщение «По вашим ответам ни одно из проверенных оснований сейчас не подходит. Это не значит, что вариантов нет совсем… Рекомендуем индивидуальный разбор.» (Digital nomad не подходит из-за клиентов в Болгарии).

Контроль: на вопрос о клиентах в Болгарии ответить «Нет» → ✅ «Digital nomad» (доход `35000` не ниже 31 010 €, жильё «Да»).

## 6. Гражданин ЕС

Кнопками: для себя; гражданство «Страны ЕС, ЕЭЗ или Швейцарии»; чем заниматься: «Работать по найму или на себя».

Ожидание: ✅ «Пребывание гражданина ЕС, ЕЭЗ или Швейцарии» (виза D не нужна; документ о пребывании подаётся в течение 3 месяцев). Основания для граждан третьих стран (ВНЖ пенсионера и т. п.) не показываются.

Контроль: «Ничего из этого» → «ни одно из проверенных оснований не подходит».

## 7. Гражданин Болгарии

Кнопками: гражданство «Болгарии».

Ожидание: сообщение «Вы указали болгарское гражданство: гражданину Болгарии разрешение на проживание не нужно. Если вопрос касается членов семьи с другим гражданством, напишите об этом — разберём отдельно.» Список оснований не показывается.

## 8. Нет подходящих вариантов

Кнопками: для себя; гражданство «Другой страны»; доходы «Ничего из этого»; связи «Ничего из этого»; жильё «Нет».

Ожидание: сообщение «По вашим ответам ни одно из проверенных оснований сейчас не подходит… Рекомендуем индивидуальный разбор.» Кнопки результата («Изменить ответы», «Начать заново», «Заказать консультацию») работают.

## 9. Семья с детьми

Кнопками: «Для себя и семьи» → «Супруг(а)» и «Дети», детей `2`. Основной заявитель — как в сценарии 4 (IT-удалёнщик, доход `40000`, жильё «Да»). Для супруги: гражданство «Другой страны», доходы «Ничего из этого», документ о браке «Да». Для каждого ребёнка: гражданство «Другой страны», документ о рождении «Да», «Ребёнку уже исполнилось 18 лет?» «Нет».

Ожидание: главный вариант ✅ «Digital nomad»; в блоке «Семья» — «Супруг(а)», «Ребёнок 1», «Ребёнок 2», по каждому основание «ВНЖ для члена семьи иностранца…» 🟡 «Возможно после выполнения условия» (у основного заявителя пока нет ВНЖ не меньше года).

Контроль: ребёнку «уже 18 лет» → для него 🧑‍⚖️ «Нужен индивидуальный разбор». Гражданин Болгарии среди детей: заметка «гражданин(ка) Болгарии — разрешение на проживание не нужно».

## 10. Изменение правил в ходе анкеты

1. В боте пройдите сценарий 1 (пенсия `400`, документ «Да», жильё «Да») до результата: ✅ «ВНЖ для пенсионеров».
2. В админке (демо-база, `APP_MODE=demo`): «Показатели» → `min_pension_bg` → измените значение 347,51 на `500` → «Сохранить в черновик» → «Проверка и публикация» → «Опубликовать» (поле даты пустое, выпуск №2).
3. В боте отправьте `/result` (или `/start` и «Показать актуальный результат»).

Ожидание: результат начинается с «ℹ️ С момента прошлого подбора правила обновились — результат пересчитан.» и статус изменился на 🧑‍⚖️ «Нужен индивидуальный разбор» (пенсия 400 ниже нового порога 500); в конце «Версия базы правил: №2».

Вариант с запланированной датой: в шаге 2 задайте «Вступит в силу» на 5–10 минут вперёд. До этого момента в боте остаётся прежний результат, после — новый, без перезапуска бота. В «Истории» выпуск виден как «запланирован», его можно «Отменить».

Устаревшие кнопки: нажмите кнопку в одном из старых сообщений после того, как анкета ушла дальше или началась заново (`/restart`). Ожидание: всплывающее «Эта кнопка устарела», состояние анкеты не меняется.

## Служебные проверки

- `/help` показывает список команд; `/restart` начинает анкету заново; `/result` показывает актуальный результат.
- `/delete` → «Удалить»: «Ваши анкеты и результаты удалены»; после `/start` анкета начинается с нуля. «Отмена»: ничего не удаляется.
- Отправка фото или документа: «Отвечайте кнопками или текстом. Не присылайте документы и фото.»
- Текст длиннее 1500 символов: просьба сократить, анкета не меняется.
- Двойное нажатие одной кнопки: второй раз не меняет состояние (кнопка несёт номер ревизии анкеты).
- «Заказать консультацию» без `CONSULT_CHAT_ID`: «Онлайн-заявка на консультацию пока не настроена.» С настроенным чатом: предпросмотр → «Отправить» → заявка приходит в чат один раз, повторная отправка из того же результата: «Заявка уже отправлена».
- Запуск бота с `APP_MODE=production` на демо-базе: бот пишет в лог `Active knowledge release is marked demo while APP_MODE=production; polling not started` и не стартует.
